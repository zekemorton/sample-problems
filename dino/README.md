# Dinosaur Dataset Parsing Interview Question

## Overview

In this interview, we will explore a dataset containing information about various dinosaurs. The dataset includes details such as the dinosaur's name, location, diet, height, weight, habitat, and time period. The goal is to assess your ability to parse and analyze data using Python. You may use any available Python libraries. 

## Dataset Structure

The dataset is structured in JSON format and contains the following fields for each dinosaur:

- **name**: The name of the dinosaur.
- **location**: The geographical location where the dinosaur was found.
- **diet**: The dietary classification (Carnivore, Herbivore, Omnivore).
- **height**: The height of the dinosaur.
- **weight**: The weight of the dinosaur.
- **habitat**: The habitat in which the dinosaur lived.
- **time_period**: The geological time period during which the dinosaur existed.
